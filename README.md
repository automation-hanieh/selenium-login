# 🔐 Automated Login Test (Selenium)

Automated login tests for [saucedemo.com](https://www.saucedemo.com) using Java and Selenium WebDriver.

## 🛠️ Tech Stack

| Tool | Version |
|---|---|
| Java | 23 |
| Selenium WebDriver | 4.18.1 |
| Maven | Latest |
| IDE | IntelliJ IDEA |

## ✅ Test Scenarios

| Scenario | Expected Result |
|---|---|
| Valid credentials | Redirects to inventory page ✅ |
| Invalid credentials | Shows error message ✅ |

## ▶️ How to Run

1. Clone the repo:
```bash
git clone https://github.com/automation-hanieh/selenium-login.git
```

2. Open in IntelliJ IDEA

3. Run `Main.java`
