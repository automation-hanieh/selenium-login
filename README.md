### Automated Login Test (Selenium)  

Automates the login process on the **SauceDemo** website using Selenium WebDriver.  

**Description:**  
Opens the browser, navigates to the login page, enters valid credentials, and verifies if the login is successful by checking the URL.  
Uses WebDriverManager to handle ChromeDriver setup automatically.  

**Example:**  
Input →  
Username: standard_user  
Password: secret_sauce  

Output →  
✅ Login successful!  
or  
❌ Login failed! Current URL: [displayed URL]
